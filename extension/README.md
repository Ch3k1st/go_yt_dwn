# Video Downloader — расширение браузера

Расширение — «глаза» программы внутри страницы. Оно смотрит, какие медиа-запросы
делает плеер, и по вашей команде передаёт найденный адрес программе Video Downloader,
которая уже качает и склеивает файл (yt-dlp + FFmpeg).

Расширение **ничего не качает само** и **не ходит никуда, кроме `127.0.0.1`**.

## Установка

Папку готовит сама программа: кнопка «Расширение» распаковывает её в `tools/extension`
и вписывает туда ключ доступа. Дальше:

1. Откройте `chrome://extensions` (в Яндекс.Браузере — `browser://extensions`).
2. Включите **«Режим разработчика»** (переключатель справа сверху).
3. **«Загрузить распакованное расширение»** → выберите папку `tools/extension`.
4. В popup расширения должно появиться «программа на :8080».

В магазин расширение не публикуется — это осознанный выбор, поэтому установка ручная.
После обновления программы нажмите «Обновить» на карточке расширения.

## Что видно в popup

У каждой находки — превью, имя, метки (тип, длительность, размер, «с куками») и
кнопка «Скачать». У потоков с несколькими вариантами рядом появляется выбор
качества; у обычного файла его нет — выбирать там не из чего.

* **Превью** берётся по порядку: картинка со страницы (`og:image`, `twitter:image`,
  `poster` у `<video>`) → кадр из потока, который снимает программа → значок по типу
  источника. Место под картинку занято всегда, поэтому строка не прыгает, когда
  кадр приезжает через пару секунд.
* **Качество** разбирается из мастер-манифеста (`.m3u8`) или `.mpd` самим
  расширением — оно в сессии браузера, с куками. Список свёрнут до одной строки на
  разрешение и не длиннее восьми пунктов: у live-манифестов вариантов бывают сотни.
* Выбранное качество запоминается (`chrome.storage.local`) и предлагается в
  следующий раз; «Скачать всё» учитывает выбор каждой строки отдельно.

## Разрешения и зачем они

| Разрешение | Зачем |
| :-- | :-- |
| `webRequest` | Наблюдать за запросами вкладки и видеть адреса медиа и **заголовки запроса** (`Referer`, `User-Agent`, `Cookie`, `Origin`). Без заголовков половина ссылок отдаёт 403. Режим только наблюдательный: трафик не изменяется и не блокируется. |
| `storage` | Хранить найденное. Список лежит в `chrome.storage.session` — это память, она не пишется на диск и стирается при закрытии браузера. Рабочий порт программы хранится в `chrome.storage.local`. |
| `<all_urls>` | Видео бывает на любом сайте, поэтому наблюдать надо везде. Это же разрешение даёт popup узнать адрес и заголовок активной вкладки без отдельного `tabs`. |
| `scripting` | Один раз, **в момент открытия popup**, прочитать со страницы картинку-превью: `og:image`, `twitter:image` и атрибут `poster` у `<video>`. Скрипт исполняется, только пока popup открыт, ничего на странице не меняет и никуда, кроме popup, не передаёт. |

Чего расширение **не** просит: `downloads`, `cookies`, `tabs`, `nativeMessaging`,
внешние домены. **Постоянных контент-скриптов нет**: в `manifest.json` нет секции
`content_scripts`, страница не трогается, пока вы не откроете popup.

Почему `scripting`, а не `activeTab`. `chrome.scripting.executeScript` требует
разрешения `scripting` в любом случае — `activeTab` его не заменяет, а лишь выдаёт
доступ к странице по жесту пользователя. Доступ к странице у расширения уже есть
из `<all_urls>` (он нужен для `webRequest`), поэтому `activeTab` в списке ничего бы
не изменил, а строку в окне разрешений добавил. Минимальная добавка — ровно
`scripting`, и используется она только на одном вызове (`grabPageMedia` в
`popup.js`).

## Что не поддерживается

* **DRM (Widevine, PlayReady, FairPlay)** — Netflix, Кинопоиск и подобные. Такие потоки
  помечаются меткой «DRM», кнопки скачивания у них нет. Никаких попыток снять защиту
  не делается и делаться не будет.
* **Приватные окна** — расширение в них по умолчанию не работает; включать вручную
  не рекомендуется.
* **Сегменты потока** (`.ts`, `.m4s`) отдельными файлами не показываются: нужен манифест
  `.m3u8`/`.mpd`. Если в списке пусто, а видео идёт — обновите страницу, чтобы манифест
  запросился заново.

## Приватность

* Никакой аналитики, телеметрии и внешних запросов.
* Куки уходят только в вашу же программу на `127.0.0.1` и только для того запроса,
  который вы нажали «Скачать».
* Ключ доступа (`config.js`) — общий секрет с программой: без него локальный сервер
  отвечает 403, чтобы произвольный сайт не мог ставить задачи в очередь.

Подробности — в `docs/extension.md` рядом с программой.
