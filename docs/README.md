# Документация — Video Downloader

Консольная утилита на Go для скачивания видео с YouTube и других платформ.
Под капотом — связка [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) (загрузка/извлечение)
и [`FFmpeg`](https://ffmpeg.org/) (склейка видео+аудио в один `.mp4`).

| Параметр | Значение |
| :-- | :-- |
| Модуль | `video-downloader` |
| Язык / версия | Go 1.23.2 |
| Точка входа | [`main.go`](../main.go) |
| Интерфейсы | Веб-оболочка (по умолчанию) + CLI (`-cli`) |
| Бинарник (готовый) | `v-down` |
| Интерфейс | Меню в терминале (на русском языке) |
| Платформы | macOS, Linux, Windows |

## Кратко: что делает программа

1. Чистит экран, рисует ASCII-логотип.
2. Проверяет, что в `PATH` есть `ffmpeg` и `yt-dlp` (иначе — выход).
3. Предлагает обновить `yt-dlp` (`yt-dlp -U`).
4. Определяет установленные браузеры и предлагает взять из них cookies (для обхода
   ограничений YouTube).
5. В цикле принимает URL и скачивает видео в папку `downloads/` под оригинальным названием.
6. Завершается по команде `exit` / `quit` / `выход`.
