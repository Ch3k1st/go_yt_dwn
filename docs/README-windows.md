# Video Downloader для Windows

Загрузка видео с YouTube и сотен других сайтов (движок — `yt-dlp` + `FFmpeg`),
очередь загрузок, история и локальная транскрибация речи. Сборка для
Windows 10/11, x64.

## Как запустить

1. Распакуйте архив целиком в любую папку. Внутри два файла, и нужны **оба**:
   - `VideoDownloader.exe` — приложение с окном (то, что запускают);
   - `v-down.exe` — движок, его запускает приложение (сам по себе он нужен
     только для работы из командной строки).
2. Запустите `VideoDownloader.exe` двойным кликом. Откроется окно программы:
   окна консоли не появится.
   - SmartScreen может предупредить о неизвестном издателе (у сборки нет
     платной подписи): «Подробнее» → «Выполнить в любом случае». Спрашивается
     один раз.
   - Первые секунды в окне крутится «Запуск движка…» — стартует фоновый сервер.
   - **Первый запуск дольше:** программа докачивает `yt-dlp` и `FFmpeg`
     (~80 МБ, один раз, нужен интернет).
3. Программа слушает только 127.0.0.1 — снаружи недоступна. Если Брандмауэр
   Windows всё же спросит про сеть, доступ можно запретить: для работы он
   не нужен.
4. Чтобы выйти — просто закройте окно. Движок и все его `yt-dlp`/`FFmpeg`
   закрываются вместе с ним, в диспетчере задач ничего не остаётся.

Мелочи, которые полезно знать:

- Второй двойной клик по `VideoDownloader.exe` не запускает вторую копию, а
  поднимает уже открытое окно.
- Размер и положение окна запоминаются между запусками.
- Работает Windows 11 «из коробки». На Windows 10 может потребоваться
  компонент **Microsoft Edge WebView2 Runtime** — если его нет, программа
  скажет об этом и даст ссылку
  (<https://developer.microsoft.com/microsoft-edge/webview2/>).

## Куда всё складывается

- Скачанные файлы: `%USERPROFILE%\Downloads\Video Downloader\downloads\`.
  Открыть папку можно прямо из программы — раздел «История», кнопка
  «Открыть папку загрузок».
- `yt-dlp` и `FFmpeg`: `%USERPROFILE%\Downloads\Video Downloader\tools\`.
- Лог приложения: `%LOCALAPPDATA%\video-downloader\app.log` — туда пишут и окно,
  и движок; этот файл нужен, если что-то не запустилось.
- Размер окна: `%LOCALAPPDATA%\video-downloader\window.json` (можно удалить,
  чтобы окно вернулось к размеру по умолчанию).
- Служебные данные окна (кэш WebView2): `%LOCALAPPDATA%\video-downloader\webview2\`.
- История загрузок хранится внутри окна программы (в его локальном хранилище)
  и никуда не отправляется.

## Что работает

- Разбор ссылки: превью, название, канал, длительность, просмотры и список
  доступных качеств.
- Загрузка: видео до 1080p (H.264 + AAC — играет любым плеером Windows),
  только аудио в `m4a` или `mp3`.
- Очередь: две задачи одновременно, прогресс, скорость, оставшееся время,
  отмена и повтор.
- История последних 200 файлов, кнопка «Показать в папке» открывает Проводник
  с выделенным файлом.
- Cookies из установленного браузера (обход «подтвердите, что вы не робот») или
  файл `cookies.txt`, положенный рядом с `v-down.exe`.
- Транскрибация: движок распознавания и модель скачиваются по кнопке при первом
  использовании. Если в сборке модуля нет, раздел честно об этом скажет.
- Светлая и тёмная тема, по умолчанию как в системе.

## Чем Windows-версия отличается от macOS

- **Перетаскивание файла в окно** для транскрибации: путь берётся только на
  macOS. На Windows выберите файл кнопкой «Выбрать файл…» (системный диалог)
  или впишите путь в поле ниже — оба способа равноценны.
- **Меню и горячие клавиши** (масштаб интерфейса, «Обновить») — только на macOS;
  на Windows их нет.
- **Разрешение системы на папку «Загрузки»** — только на macOS; в Windows его
  не спрашивают.

## Запуск из командной строки (по желанию)

`v-down.exe` работает и сам по себе, по-старому:

- `v-down.exe` — веб-оболочка: окно консоли с логом и интерфейс в браузере;
- `v-down.exe -no-open` — то же, но браузер не открывать (адрес будет в консоли);
- `v-down.exe -addr 127.0.0.1:9000` — другой адрес и порт;
- `v-down.exe -cli` — старый текстовый интерфейс в консоли;
- `v-down.exe -version` — версия сборки.

Остановка — Ctrl+C или закрытие окна консоли.

## Если что-то пошло не так

- **«Рядом с оболочкой нет v-down.exe»** — распакованы не оба файла. Положите
  их в одну папку.
- **Ошибки вида «Sign in to confirm you're not a bot»** — выберите источник
  cookies в разделе «Скачать». Если браузер запущен, Windows может не отдать
  файл cookies: закройте браузер полностью либо экспортируйте `cookies.txt` и
  положите его рядом с `v-down.exe` — он появится в списке источников.
- **Скачивание перестало работать на каком-то сайте** — обычно помогает
  обновление `yt-dlp`: удалите `tools\yt-dlp.exe`, программа скачает свежий при
  следующем запуске.
- **Программа не стартует** — пришлите `%LOCALAPPDATA%\video-downloader\app.log`.

## Сборка из исходников (для разработчика)

На macOS/Linux с установленным Go (cgo не нужен, кросс-компиляция):

- `make windows` → `dist/v-down.exe` (только консольный движок);
- `make windows-app` → `dist/video-downloader-windows.zip` — оболочка
  `VideoDownloader.exe`, движок `v-down.exe` и этот файл.
