# Руководство пользователя

## 1. Зависимости

Программе **обязательно** нужны `yt-dlp` и `FFmpeg` в системном `PATH`.

| ОС | Команда установки |
| :-- | :-- |
| **Windows** | `winget install yt-dlp ffmpeg` |
| **macOS** | `brew install yt-dlp ffmpeg` |
| **Linux (Ubuntu)** | `sudo apt update && sudo apt install yt-dlp ffmpeg` |

Для сборки из исходников нужен [Go 1.18+](https://go.dev/dl/) (проект собран на 1.23.2).
Проверка: `go version`.

## 2. Сборка

```bash
go build -o v-down main.go
```

В репозитории уже лежит готовый бинарник `v-down` (macOS).

## 3. Запуск

- **Windows:** `.\v-down.exe`
- **Linux / macOS:** `./v-down`

## 4. Работа с программой

1. При старте программа проверит зависимости и предложит обновить `yt-dlp` — рекомендуется
   соглашаться, если возникают ошибки скачивания.
2. Выберите источник cookies (см. ниже) или вариант `0) без cookies`.
3. Вставьте ссылку на видео, например `https://www.youtube.com/watch?v=...`, и нажмите Enter.
4. Видео сохранится в папку `downloads/` под оригинальным названием в формате `.mp4`.
5. Для выхода введите `exit`, `quit` или `выход`.

## 5. Cookies (обход ограничений YouTube)

Если YouTube требует «Sign in to confirm you're not a bot», помогают cookies из браузера.
Программа автоматически находит установленные браузеры и предлагает их в меню.

Два способа передать cookies:

- **Из браузера** — выберите браузер из списка; используется
  `yt-dlp --cookies-from-browser`.
- **Файлом `cookies.txt`** — положите файл рядом с программой или в текущую папку;
  он будет найден автоматически и передан через `yt-dlp --cookies`.

## 6. Формат и качество

По умолчанию выбирается лучшее видео с кодеком AVC (H.264) + аудио m4a, с последующей
склейкой в `.mp4` через FFmpeg. Плейлисты отключены (`--no-playlist`) — скачивается
только указанное видео.

## 7. Частые проблемы

| Симптом | Решение |
| :-- | :-- |
| `ffmpeg`/`yt-dlp` не найдено | Установите зависимости (раздел 1), проверьте `PATH`. |
| Ошибки извлечения / «not a bot» | Обновите `yt-dlp` (`yt-dlp -U`) и/или включите cookies из браузера. |
| Видео не скачивается | Убедитесь, что ссылка корректна и видео доступно в вашем регионе. |
