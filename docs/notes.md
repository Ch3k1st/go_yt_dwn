# Особенности и технические решения

## Обход «Sign in to confirm you're not a bot»

В `downloadVideo()` передаётся:

```
--extractor-args youtube:player_client=tv,web_safari,default
```

Используются TV- и Safari-клиенты YouTube, которым не требуется PO-токен. Если YouTube
ужесточит проверки — остаётся резервный путь через cookies из браузера (меню при старте).

Дополнительно для устойчивости:

- `--retries 3` — повтор при сбоях.
- `--sleep-requests 1` — пауза между запросами, чтобы не упереться в rate-limit.

## Yandex Browser

`yt-dlp` не знает Yandex Browser по имени. Решение: браузер заводится в таблице кандидатов
под `id = "chrome"` (он Chromium-совместимый), а путь к его профилю передаётся явно через
поле `profile` → `--cookies-from-browser chrome:<путь-к-профилю>`.

## Выбор формата

```
-f "bv*[vcodec^=avc]+ba[ext=m4a]/best[ext=mp4]/best"
--merge-output-format mp4
```

Приоритет: AVC-видео + m4a-аудио → лучший готовый mp4 → лучший доступный формат.
Склейка дорожек выполняется FFmpeg (`--downloader ffmpeg`).

## Прогресс загрузки

Кастомный шаблон (`--progress-template`) выводит проценты, скорость и ETA в цвете,
вместо стандартного прогресс-бара `yt-dlp`.

## Вывод и оформление

Весь интерфейс на русском языке, оформлен ANSI-цветами и Unicode-рамками. Логотип —
ASCII-арт «VIDEO DOWNLOADER by Ch3kL1st».
