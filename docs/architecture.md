# Архитектура и устройство кода

Весь код находится в одном файле — [`main.go`](../main.go). Внешних зависимостей Go нет
(используется только стандартная библиотека). Вся «тяжёлая» работа делегируется внешним
бинарникам `yt-dlp` и `ffmpeg`, которые вызываются через `os/exec`.

## Поток выполнения

```
main()
 ├─ clearScreen()        очистка терминала (clear / cls)
 ├─ showLogo()           ASCII-логотип
 ├─ checkDependencies()  проверка ffmpeg и yt-dlp в PATH
 ├─ askForUpdate()       опциональный yt-dlp -U
 ├─ askForBrowser()      выбор источника cookies
 └─ for { ... }          главный цикл:
       ├─ читает URL
       ├─ isExitCommand() → выход по exit/quit/выход
       └─ downloadVideo() → запуск yt-dlp
```

## Ключевые структуры

### `browserInfo`

Описывает источник cookies:

| Поле | Назначение |
| :-- | :-- |
| `id` | Имя браузера для `yt-dlp --cookies-from-browser` (например `chrome`, `firefox`). |
| `display` | Человекочитаемое название для меню. |
| `profile` | Путь к профилю-переопределению (нужно для браузеров, которых `yt-dlp` не знает по имени — например Yandex). |
| `file` | Путь к `cookies.txt`; если задан — используется `--cookies <file>` вместо `--cookies-from-browser`. |

Глобальная переменная `cookieSrc browserInfo` хранит выбор пользователя на всё время сессии.

## Функции

| Функция | Что делает |
| :-- | :-- |
| `main()` | Инициализация и главный цикл ввода URL. |
| `isExitCommand(s)` | Распознаёт команды выхода: `exit`, `quit`, `выход`. |
| `ensureDependencies()` | Находит или скачивает `ffmpeg` и `yt-dlp` (см. [`deps.go`](../deps.go) и [dependencies.md](dependencies.md)); при неудаче — инструкция и `os.Exit(1)`. |
| `askForUpdate()` | Спрашивает `[y/n]` и при согласии запускает `yt-dlp -U`. |
| `detectBrowsers()` | Сканирует ОС-зависимые пути установки браузеров и наличие `cookies.txt`; возвращает список доступных источников cookies. |
| `askForBrowser()` | Печатает меню браузеров и сохраняет выбор в `cookieSrc`. |
| `downloadVideo(url)` | Собирает аргументы и запускает `yt-dlp`, выводя прогресс. |
| `printDivider(label)` | Рисует разделитель-заголовок фиксированной ширины (60 символов). |
| `pause()` | «Нажмите Enter, чтобы продолжить…». |
| `clearScreen()` | `clear` (Unix) / `cls` (Windows). |
| `showLogo()` | Цветной ASCII-логотип. |

## Определение браузеров

`detectBrowsers()` содержит таблицу кандидатов с путями установки для каждой ОС
(`darwin` / `linux` / `windows`). Логика:

1. Сначала ищется `cookies.txt` рядом с исполняемым файлом и в текущей папке.
2. Затем для каждого кандидата проверяется существование пути установки через `os.Stat`.
3. Найденные браузеры попадают в меню; первый в списке помечается как «по умолчанию».

Поддерживаемые браузеры: Chrome, Firefox, Safari, Edge, Brave, Opera, Vivaldi, Chromium,
Yandex Browser (через профиль под ридером `chrome`).

## Цветовой вывод

В начале файла объявлены ANSI-escape константы (`cReset`, `cBold`, `cRed`, `cGreen`,
`cYellow`, `cBlue`, `cPurple`, `cCyan`) — используются для оформления всего вывода.
