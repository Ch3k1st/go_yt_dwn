# Зависимости (yt-dlp и ffmpeg)

Программе нужны `yt-dlp` (загрузка) и `ffmpeg` (склейка/конвертация). С версии «update»
их **не нужно устанавливать вручную** — при первом запуске программа сама их находит или
скачивает.

## Логика поиска (для каждой зависимости)

При старте `ensureDependencies()` ([`deps.go`](../deps.go)) ищет бинарник в таком порядке:

1. **`tools/`** рядом с программой — если уже скачан ранее, используется он.
2. **`PATH`** — если установлен в системе (например через `brew` / `winget` / `apt`).
3. **Скачивание** — если нигде не найден, качается в `tools/`.

Если скачать/распаковать не удалось, программа печатает понятную инструкцию по ручной
установке и завершается — то есть поведение не хуже прежнего.

## Откуда качаются бинарники

| Зависимость | ОС | Источник |
| :-- | :-- | :-- |
| yt-dlp | Windows | `yt-dlp.exe` (GitHub releases) |
| yt-dlp | macOS | `yt-dlp_macos` |
| yt-dlp | Linux | `yt-dlp_linux` |
| ffmpeg | Windows | `yt-dlp/FFmpeg-Builds` (win64, zip) |
| ffmpeg | Linux | `yt-dlp/FFmpeg-Builds` (linux64 / linuxarm64, tar.xz) |
| ffmpeg | macOS | `evermeet.cx` (zip) |

## Где хранятся

Папка `tools/` рядом с исполняемым файлом (портативно). Если рядом с программой писать
нельзя, используется системный кеш пользователя (`os.UserCacheDir()/v-down/tools`).
Папка `tools/` добавлена в `.gitignore`.

## Нюансы по платформам

- **Windows / Linux** — полностью автономно: скачиваются статичные сборки, ничего ставить
  не надо.
- **macOS на Apple Silicon (arm64)** — сборка ffmpeg с evermeet.cx собрана под Intel
  (x86_64) и запускается через **Rosetta**. На большинстве машин Rosetta есть; если нет —
  поставьте ffmpeg через `brew install ffmpeg` (он будет подхвачен из `PATH`).

## Связь с путями в коде

После `ensureDependencies()` глобальные переменные `ytDlpPath` и `ffmpegPath` указывают на
реальные бинарники. При скачивании видео yt-dlp получает явный флаг `--ffmpeg-location`,
поэтому ffmpeg из `tools/` находится даже когда его нет в `PATH`.
